# Receipts

An agent that doesn't believe the marketing.

Paste a URL (a software vendor, an online shop from an ad, or a marketplace listing) and Receipts returns a verdict: **Trust**, **Caution**, **Avoid** or **Unsure**. Every reason links to a source you can open and check.

> AI can fake a company's website in an hour, but it can't fake that company's history.

Built at the Agentic Hackathon: From Research to Commerce (AI Agents Berlin, 27 November 2026), Research Agents track.

## Setup

1. Copy `.env.example` to `.env` and fill in the keys.
2. Setup and run instructions follow as the project is built.
